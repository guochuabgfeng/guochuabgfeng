# Claude / Agent 技能对齐文档

> 仓库现状：当前代码库为极简初始化状态（仅含 `.gitkeep`），暂无业务代码。
> 本文档用于先行定义技能规范，后续可随代码演进持续补充。

## 1) 洁癖 Skill

**作用**：对齐当前代码库，更新 `Agent/Claude.md` 文档，保持文档结构、术语与实现状态一致。

### 触发场景
- 新增/删除目录、模块或脚本后。
- 提交前需要校验文档是否与代码一致。
- 评审反馈指出文档过期或含糊时。

### 执行步骤
1. 扫描仓库结构与关键文件变更。
2. 对照本文档条目核验：目标、输入、输出、边界。
3. 更新不一致项并记录“变更原因”。
4. 提交前进行一次“文档-代码一致性复查”。

### 输出标准
- 文档中的路径、模块名、流程描述可在仓库中定位。
- 概念定义避免歧义；术语前后一致。
- 明确“当前已实现 / 规划中”边界。

## 2) 双时序线概念分析 Skill

**作用**：进行 vibe reading 场景下的“双坐标时序分析”，帮助深入理解概念演化与叙事结构。

### 核心概念
- **时间线 A（事件时序）**：客观事件发生顺序。
- **时间线 B（认知时序）**：读者/角色获得信息的顺序。
- **双坐标视角**：以 A、B 两条线交叉定位“理解断点”和“意义反转点”。

### 分析框架
1. **抽取节点**：列出关键事件、信息披露、观点变化。
2. **双线映射**：将每个节点映射到 A/B 时间轴。
3. **差值识别**：标记 `A-B` 的错位区间（悬念、误导、迟到信息）。
4. **机制解释**：说明错位如何影响情绪、判断与主题。
5. **结论沉淀**：输出概念定义、证据点、可复用洞察。

### 典型产物
- 双时序表格（事件时间 / 认知时间 / 影响）。
- 概念卡片（定义、反例、边界条件）。
- 深读结论（主题推进路径、叙事策略）。

## 3) Vibe Reading Skill

**作用**：进行“氛围阅读”——在不牺牲文本证据的前提下，捕捉语气、节奏、意象与情绪场。

### 方法步骤
1. **第一遍：感受采样**
   - 记录直觉情绪词（压抑/松弛/疏离/亲密等）。
2. **第二遍：证据回填**
   - 为每个情绪判断补充对应语句、意象或结构证据。
3. **第三遍：结构归因**
   - 分析情绪由何种叙事机制产生（视角、时序、修辞、留白）。
4. **第四遍：跨段校正**
   - 检查局部感受是否与全书/全文主题一致。

### 输出模板
- **氛围摘要**：一句话概括整体气候。
- **证据清单**：3-5 个关键文本证据。
- **机制说明**：说明“为何会产生该氛围”。
- **误读风险**：指出可能的主观偏差来源。
